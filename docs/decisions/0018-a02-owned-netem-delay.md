# ADR0018：A02单向NetEm时延与独立双端测量

2026-11-26。按既有A02设计实施，保持V1.3附加单向200/1000/3000ms，不调整正常网络参数上限或业务期限。

`0.4-fault.2`新增LinkDelay和方向，旧`0.4-fault.1`仍接受A01。站点作用于独立接入出口，区域/全局作用于汇聚出口；同事件不同时叠加两层。出口必须有配置化NetEm基线，命名空间及接口只从本次自有拓扑展开。主站只执行原背景业务，故障计划/读回均在Oracle目录。

使用qdisc change保留原qdisc和队列，不使用replace/delete撤销。显式保留limit=10000、jitter和seed，读回比较完整options及handle/root；施加前检查所有基线，部分失败恢复已触及出口。tc不显式带limit/seed的开发探针002读回不一致，已拒绝。probe003在有排队数据报时撤销，60条全部交付，qdisc无丢弃、最终排空。seed显式重设会重新初始化随机序列，因此不声称随机流连续，也不要求配对逐包一致。该探针是内核机制验证，不是协议验收。

实际参数恢复和队列排空分别记录。正常运行异步等待排空（不阻塞物理更新），随后保留新发起的完整GI；取消先恢复参数，剩余恢复观察明确截尾。失败不计有效异常实验。原qdisc drops、工具drops、解析、同端日志对齐、物理及Arrow门槛保留。

独立QC不调用变更函数，从冻结配置和manifest独立推导出口、逐操作核对原基线/附加/恢复。双端使用连接轮次、地址/端口、方向、完整APDU唯一关联；歧义及未匹配单列，禁止最近时间强配。逐端TCP序列重组去重重传，测量为完整APDU可交付时延（含有序交付等待），不能宣称逐IP包传播时延。量化诊断断言见既有A02计划实施补记，与业务期限、标签定义和正常质量门禁分离。A02无A01的TESTFR核算豁免，仍要求无未解释的双端字节丢失。

正式分层标签及P03/P04/P06在V0.4d实施。本片只验证机制、数据质量、实际影响和恢复事实；低强度没有业务违约时如实保留。
