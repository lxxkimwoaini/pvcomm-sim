# ADR 0020：配对与独立业务标签证据

日期：2026-11-26。状态：已实施，真实配对验收待执行；不是完整V0.4通过记录。

配对复用唯一隔离运行器。`0.4-pair.1`明确正常成员与改变成员；共享条件仅去除运行身份及诊断场景名，P03另允许授权维护计划差异，所有气象、物理、初态、空间、网络基线、种子和业务计划仍逐字段一致。P06两成员都在10秒停用/40秒恢复，27秒发同一命令；正常实际拒绝，15秒处理异常在42秒后处理并实际迟到确认。它是开发实验配置，不改正式参数。

标签`0.4-label.2`按站点包含诊断层和业务约束记录。故障起点使用 A06 实际 `terminal_fault_feedback_hold` 事件；通信影响仅在机制 QC/实际 withheld 或时延测量有独立证据时记录；完整恢复要求撤销后的新总召唤请求、确认、结束及完整测量对象，首条普通遥测不再被当作恢复完成。命令沿用已有保守事务审计，独立标签QC另从P0协议对象、主站事件、终端及物理证据复核，不能凭`transmit(False)`或注入类型生成超时。功率可达性遵循`min(target, p_avail)`；低于目标本身不是通信异常。无有效确认在3秒期限才可判定；缺反馈按命令实际记录的10–60秒期限，不统一替换为固定期限。

接收新鲜度沿用主站已有`2×遥测周期+1秒`观测有效性政策，检查1001/1002/1003/1008/2001，逐站覆盖。它表示收到有效数据的时间间隔，不宣称无时标104数据的真实设备采样时间或独立可信气象。只对已提前发布的主站维护计划，在授权窗口和既有15秒恢复宽限内豁免；结束后仍缺数据产生违约。每个违约保留独立可辨识时刻、恢复和截尾。完整恢复仍依机制QC中的新总召唤证据，第一条数据不自动等于设备物理真值最新。

`fault_applied`来自独立机制核验；主业务标签来自命令与新鲜度，故障无违约允许主标签false。仅有应用层抑制及双端字节一致，不能证明不存在一切传输退化，`transport_impact`保留null及原因。实验质量失败为invalid，证据歧义为uncertain。M3保持无独立信息来源；标签、P1、物理和注入均为Oracle，默认M2接口和白名单不增加这些数据。

JSONL与Zstandard Parquet保存相同嵌套schema，Arrow显式索引层字段和完整JSON负载逐值读回；来源哈希包含原PCAP及日志，证据引用包含原事件或协议对象身份、tier、available_at及用途。在线引用不得使用Oracle或期限之后的数据；恢复证据为回顾性，不回填未来模型输入。原始证据与旧QC不覆盖。标签生成与标签QC分开执行、各自原子写入。

配对固定报告上下行包数、字节数、窗口及活动持续时间、到达间隔均值/P50/P95的相对距离。首个功能切片不设事后相似度阈值，不声称已完成统计匹配或40次/类覆盖；实际差异和业务对比单独报告，不删改原PCAP或依模型筛样。正式匹配策略及覆盖仍按V1.3后续冻结验收。

标签QC v3追加必要证据覆盖检查。每条命令必须引用该事务主站发送事件，valid命令须有P0协议对象引用，新鲜度须引用原有效接收事件或业务起点，每站须引用独立机制/正常QC。删除整组引用、重复引用或改写tier均应失败。v2及更早QC原件保留。
