# ADR 0004：串行命令的保守证据关联

2026-11-25。修复 V0.1 实现，不修改异常标签、正式期限或划分。

主站序列生成本地唯一 task_id，锁住实际 transmit 过程。IEC 104 无应用 task_id，不能把终端同值事件强行赋予主站 ID。独立 QC 使用站点/点号、CA、类型、方向、TCP flow、值、时间及唯一性；接受/确认/线上命令有多个候选即失败。所有选中证据仅消费一次。同站同点下一条发送是上一条关联的排他上界；确认 [发送,确认截止)，反馈 [终端接受,min(执行截止,下一发送))。设定值反馈可能先于同步 transmit 返回，不强制伪造相反时序。

新版 QC 为 v01-evidence-v2，不覆盖 v1；旧单次 limit/release 运行仍可核验。执行窗口暂沿用 V0.1 的10s，V0.2 显式记录动态执行期限，可用功率不足另按物理可达目标核验。歧义/证据不足不称成功，不据此直接生成正式标签。纯合成事件 fixture 仅单元测试，真实保留数据三份重新独立验算。
