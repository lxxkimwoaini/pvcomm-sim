# ADR 0005：V0.2 开发物理模型及历史输入

2026-11-25。范围为三站开发验收，不冻结正式论文参数、标签、数据划分；V0.1 固定出力路径保留。

采用 NASA POWER Hourly API、辉县附近背景网格经纬度35.4/113.8、2024-06-01至30 UTC（先下载三天预检，后另目录扩展整月筛选，原输入保留）。实际响应 API v2.10.5，sources=MERRA2/SYN1DEG/POWER。这是历史卫星/再分析产品，不是辉县现场气象实测。辐照参数 Wh/m² 为一小时能量，除以1h得到该小时平均 W/m²；逐秒电气驱动使用该小时均值的零阶保持，原始时间与实际回放 UTC 分开，不声称恢复了小时内云影。

使用权限依据 NASA Earth Science full/open data policy，按 POWER referencing 指南记录服务/版本/访问时间与致谢；不擅自写 CC 许可证。来源与政策页面随下载缓存，原始 SHA256、规范化输入 SHA256均记录；政策/来源快照仅本地保留。原始完整响应含易变的处理耗时，重复下载比较排除 times 的规范化内容哈希。输入缺测、重复/非整小时、单位/坐标/版本不合约、间断及范围越界全部失败，不补零。ERA5/Oahu仍是后续来源候选；本次Oahu下载入口403/TLS失败，不绕过安全校验，不声称已验证秒级N03。

pvlib 0.16.1 以太阳位置、isotropic 辐照转置、SAPM open_rack_glass_glass 温度及 PVWatts DC/AC 计算可用交流功率。组件/逆变器参数配置化；DC/AC容量与逆变器DC输入额定参数明确分开，损耗作用在DC。不添加随机电气量。后验物理真值只写 truth。

三站额定30/100/300kW，S/P=1.1、DC/AC=1.2、朝南倾角30°、gamma=-0.004/°C、DC损耗14%、逆变器额定效率0.96，均为可替换的工程仿真假设而非产品标定或现场参数。设备限制目标范围、运行/开关/故障状态、P上下行斜率、Q斜率及P优先能力圆；资源不足/离网先满足物理边界，单独留原因。负载及20/0.4kV、630kVA变压器、3段径向线路参数同样标注合成。pandapower3.5.6 sgen采用发电注入正的MW/Mvar，输出线电压kV和平衡近似电流A。潮流每5s与接受命令事件补算，不收敛报失败，禁止伪造电压。

每个RTU进程持有自身物理模型，只在真实c104命令回调内accept更新设定值；独立scenario电气工作器读取RTU追加完整记录快照运行三站潮流，再提供带求解时间的电压快照。主站进程及M2 Web不读这些IPC/真值文件。共享宿主单调原点；电气1s、潮流5s、协议1×，采集与UI独立。重复同值指令保留每次接受计数及事件。

新增0.2配置/真值Arrow使用独立版本，不静默扩展旧六表。新增IOA1004电流、1005辐照与1008可用功率是明确的实验点表扩展，经真实协议传送后才进入M2；它们同链路，不能视作独立可信M3。未收到值保持未知。


历史背景选择：晴朗候选2024-06-23T04:00Z，GHI1002.67、DHI/GHI0.17617、DNI814.53；多云候选2024-06-02T03:00Z，GHI544.60、DHI/GHI0.75593、DNI98.65。仅为历史辐照特征分层，不宣称现场云量标签。辐照变化配置跨越2024-06-03T05:00Z真实小时均值边界；属于重分析输入阶跃，不能作为实测秒级N03云影。整月规范化哈希72a8d6275ef89029b6b34e73d0cc68708ee749eef69dcf59abe65d0fe13346bd。

drvfs预检发现替换已存在IPC路径可能瞬时不可读，首轮失败运行保留。改用单写者追加JSONL，读者仅消费最后完整换行记录，截断尾不覆盖上次测量，完整坏行失败；时间新鲜度限制仍执行。该实现不承诺断电持久性，真实原始事件另由RunRecorder保留。


补充秒级模型切片：新NLR域名入口实际可下载Oahu 201003.zip（本地26,242,811字节，SHA6ce110233785bd150f5de698729465a41a41eb192ffc66216d3b0aa9cfa02fd2），但原站sitehome明确“data and any subset may not be publically redistributed”，与OEDI CC BY4.0标记冲突。因此不解析进平台、不再分发，也不据此声称真实云影验收。输入保留在忽略目录作来源审计，不删除用户数据。

为验证物理快速变化，采用显式可选 `advected_grey_optical_layer`：以10m/s平流、半宽200m、中心45s的有限层，光学厚度tau(x)=1.5 cos²(pi*x/400)（|x|<200m，其外0），透过率T=exp(-tau)。在真实晴朗历史背景上GHI/DNI/DHI同时乘T，温度/风保留原背景。它是简化灰色消光层近似，未建多次散射、云边增强或实际云微物理，不能解释为Oahu/辉县实测云影。source_ghi与透过率均写Oracle表，保留真实来源与模型变换；M2只见实际IEC遥测。此开发切片不修改正式气象分布/场景参数、标签或数据划分，后续正式实验需校准。模型基于Beer–Lambert光学消光和已声明平流边界，禁止将此层衍生曲线称为真实历史秒级数据。


独立重算精度决策：运行模型基于保留的单调纳秒原点，source_weather_ts的ISO表示只有微秒精度。秒级扰动下用ISO反推elapsed导致约3.3e-5的POA偏差；v2/v3失败报告保留。临时v4的1e-4容差不用于最终验收，v5恢复原1e-6并用(model_mono_ns−clock_origin.ts_mono_ns)/1e9重算；ISO仅用于1µs映射一致性检查。最终云影证据全量重算误差0，不改变运行数据或物理/QC门槛。版本目录保留所有历史，不以新通过报告覆盖失败报告。
