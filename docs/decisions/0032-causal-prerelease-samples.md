# ADR0032：首版因果窗口、分组与轻量实验

2026-11-27，依据用户授权实施V0.5；继承V1.3的60秒右对齐窗口和5秒步长，标签采用`t-1ns`状态、半开区间任意覆盖及合并覆盖比例。故障作用不能代替业务finding；截尾保留、覆盖后旧事务终止、unknown不作负例。预热与初始化不生成完整训练窗口。

先按相同天气原始日期（包括跨午夜）、显式source_group_id、pair_id及复用实测模板建立传递连通组，再冻结约60/20/20。同组不跨区；首版不承诺各类均匀，缺类如实报告。灰光学云层是物理模型算法，不将其误当实测高频模板；相同日期及初始轨迹仍合组。S2未见站点专项后续补独立运行组，不随机拆同步站点。

模型输入仅P0 packets/APDU/objects和observed主站日志，经available_at和事件时间的较晚者严格小于游标。M2点值携带实际接收年龄/品质；缺失为null，陈旧不补Oracle。跨站均值只使用当时新鲜有效同链路观测，显示覆盖率，不宣称独立可信气象。SQLite仅为可清理的索引，原件不改。

特征表只有不透明sample_id与白名单数值；运行、场景、分区、故障及Oracle标签单独存表。业务规则基线独立使用主站已知计划、期限及已收确认/反馈，最终规则输出不进入学习特征。首次预处理只在训练拟合，IF/EWMA只用正常训练行，RF用监督训练行；缺失指示和中位数、标准化参数留存。验证F1选阈值，同分取最高阈值；验证单类时按预定99分位保留限制。测试不参与阈值和超参选择。

固定IF/RF100棵树、RF深度6/叶最少2、IF采样256、EWMA alpha=0.3、三随机种子7/17/27（确定性规则/EWMA一次）。误告警按10秒合并，每段只能匹配一个事件。重叠freshness findings合并为站点业务事件；漏检保持截尾，完整事件列表保留。单位时间误告警分母为有效正常端点对应5秒槽的站点小时，避免重叠60秒重复计时。PR-AUC明确采用非插值average precision。均值/种子标准差不充当独立组置信区间。

这是预发布可用性验证，不代表现场精度或论文创新。保留实际小样本、单类/缺类、不平衡和重叠窗口相关性限制；不通过调统计相似阈值或随机窗口划分取得好分数。M0/M1从同一M2表按累计白名单投影，可免重复扫描与生成原件。
