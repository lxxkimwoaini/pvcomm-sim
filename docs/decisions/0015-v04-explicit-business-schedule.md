# ADR0015：显式正常场景组合契约与因果调度

2026-11-26，V0.4b实施决策。保持0.1/0.2/0.3配置、协议、物理与正常QC语义不变。

新增`0.4-scenario.1`外层组合V03Config；业务计划必须显式给出，空数组表示没有控制指令，不能进入旧版固定限发/解除路径。旧`run`命令不变，新增`run-scenario`只使用受控隔离运行器。编排分配随机不含场景编码的唯一run_id（可显式指定经校验的ID用于复现），已有目录拒绝覆盖。原始外层配置、有效外层配置及展开计划写truth/scenario，运行器为旧端点/电力模块保存编译后的V03配置。

每项计划有不含场景类别的schedule_id、站点集合、逻辑时刻与可选正向整数抖动。抖动由seed和schedule_id独立确定；保存展开计划和规范化哈希。配置验证完整抖动范围内同站60s保守业务窗不交叠，不靠进程启动时间改变业务时刻。不同站任务允许并行，逐站命令仍走已有锁及真实c104确认机制；按容量/已收到可用功率分配复用已有算法和缺测排除策略。运行中总召唤使用真实协议，不将旧遥测当作本次响应。

诊断场景代码、来源组、配对组、完整未来计划仅存truth/scenario；主站按到期任务记录实际下达意图及协议事实，所有事件保留available_at。未来任务不提前注入M2。合法维护仍使用已验收的已知维护授权及真实STOPDT/恢复流程。本地正常设备操作沿用独立物理入口，不改远方命令接受条件。

新增场景验收在实验完整性/数据质量之后核对实际任务成员、独占事务、总召唤和正常边界，保留旧normal_regression结果，不将场景代码当正常标签。该契约首版仅正常开发场景，未实现异常施加或正式标签，不据此声称完成V0.4。新来源适配及完整N01–N10覆盖按后续实际证据分列。

按V1.3第14.1节，同一原始气象日期必须共同分组。开发模板的source_group_id按NASA规范化来源哈希和UTC原始日期确定，不能按正常场景代码/种子拆组。早期4ab3fc5小规模功能证据保留原始模板组ID，覆盖报告另给共同来源组映射，禁止把旧模板ID直接用作跨分区依据；不修改已有源文或运行manifest。本阶段没有执行数据集划分。跨多日/多来源的重叠分组连通关系由后续V0.5统一核验，不仅依赖单一字符串。
