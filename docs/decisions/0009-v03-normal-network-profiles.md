# ADR0009：正常链路NetEm参数与实际读回

2026-11-25。30站360秒零附加时延预检55a2d1b全QC通过，但不能替代V1.3第6.1节差异化正常网络模板。增加可选的每区域uplink及每站access_link，不修改0.1/0.2配置或已冻结运行。旧V0.3前置证据仍用对应冻结源码核验；新增默认字段会影响旧V0.3规范化哈希，不冒称新QC可原地覆盖旧报告。

开发候选配置：每区域汇聚单向3±1ms，每站接入按索引交替7±2、37±7、97±19ms，端到端名义10/40/100ms、抖动量级3/8/20ms，均位于方案L1/L2/L3范围。NetEm默认均匀抖动、不配置额外随机丢包（0在正常范围内），双向分别配置；区域种子1104起步、站点2104起步，相反方向加1。不是现场测得链路，不冻结正式研究参数。共享汇聚排队与TCP机制可使实测不同于名义参数，必须保留实际确认/PCAP指标。

只对本次拥有的namespace/veth执行tc；不会改宿主根qdisc或默认路由。WSL独立临时namespace探针真实返回NetEm delay=.007/jitter=.002/seed104，探针已清理，输出保留outputs/probe_netem.py所对应工具记录。完整仿真初始化和结束均读取tc -j -s -d qdisc，逐条核对delay/jitter/seed；初始/最终统计入manifest。QC v03-power-v3另验qdisc数量和零qdisc丢包，原始抓包零丢包、99.5%解析、100ms对齐和业务期限门槛不改。按3/10/20/30重新验证实际链路，不由配置或单元测试推断实跑通过。
