# ADR 0027：显式 Oracle 实验队列与本地执行器

日期：2026-11-26。状态：36b8e72首切片真实API→授权执行器→c104及启用态浏览器验证通过；完整科研工作台仍未完成。

科研工作台使用 `/api/diagnostics/experiments` 独立入口。M2 原观测接口及默认页面不接收场景、注入、标签、队列或事后质量信息。服务端只有显式配置 `PVCOMM_EXPERIMENT_ROOT` 时开放管理接口；该本地服务不面向公网，写请求拒绝跨源浏览器 Origin。

网页提交只允许既有 N01～N10、六类 P0 和四种开发配对模板的受限参数；不接受文件路径、地址、脚本或系统命令。生成完整冻结矩阵、SHA256、随机种子及排队记录。网页不提升权限、不启动网络；授权 Linux 执行器读取同一目录，复用现有 run_batch，最大并发仍为1。执行器与网页解耦，关闭网页不终止任务。

队列新增紧凑 summary.json 投影，不包含逐文件哈希清单；轮询不读取持续增长的详细manifest。manifest、原始证据及完整产物索引仍保留。历史队列暂不直接接入网页；独立离线审计不回写旧manifest。新任务以排他目录及原子request提交，受控执行器校验请求和矩阵哈希后才运行。

先交付场景提交、队列状态、覆盖及独立质量/标签诊断；完整配对曲线、PCAP事件定位、导出及规模验收按后续切片完成。管理界面不冒称检测告警或V0.4整体验收。

证据切片延续同一Oracle边界：标签引用在服务端形成不透明键，完整SHA验证后用限量临时SQLite偏移索引定位原始记录；协议对象直接链接实际P0帧号，不能用诊断数据回填M2。图形时间轴只投影正式标签，合法拒绝为正常结果点，区间未知不等于业务异常。终态运行按文件导出带SHA清单和流式下载，不写回证据、不提供任意路径。Windows深层UNC证据采用扩展文件系统路径，避免旧Win32 MAX_PATH限制。完整配对图及统计交互另行完成。
