# ADR0013：计划维护先完成协议停传和连接关闭

2026-11-26。V0.4a三站复验v04a_s2（4b23363）在210s真实运行中完成缺测排除、合法拒绝和后续调控，完整APDU2511/2511，但PV01终端回调缺少一个P1的S帧`68040100ae01`，独立实验质量正确失败，原始证据保留。

该帧在1795659624607405000ns到达P1，晚于已记录server.stop完成时刻1795659624592516871ns约14.889ms。它来自维护时网络中仍在途的确认，服务器应用读线程已停止。现有QC仅允许实际stop调用内的特定接收控制尾帧；不扩大该窗口、不豁免丢失回调、不删帧或放宽对齐门槛。

对V0.3兼容运行器中的**已授权计划维护**，主站在场景时刻先请求真实STOPDT，等待OPEN_MUTED回调，再主动disconnect并等待CLOSED回调。控制器获得本次私有就绪标记后才暂停RTU通信；设备物理循环继续。维护结束请求重新连接，已有恢复总召唤和当前状态核验保留。握手使用实际状态条件和原有期限，不添加任意sleep。

维护调度与区域任务并行，错误传播为运行失败；线程和协议端点在finally清理。无主站确认则不创建就绪标记，不伪称已停传。非计划断联不使用该握手，不能把故障改为正常维护；V0.1/V0.2路径不变。V0.3旧冻结源码和原件保留，修复后旧配置另做真实兼容回归，PCAP不承诺字节相同。正常QC与实验QC规则均不因本修复放宽。
