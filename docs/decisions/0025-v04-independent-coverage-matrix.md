# ADR 0025：独立覆盖矩阵与规模门禁

日期：2026-11-26。状态：配置实现及普通测试完成，规模真实实验未验收。

复用已有配置、隔离运行器、真实协议和QC。场景构造器新增可选site_count；默认三站的区域划分、业务和序列化保持不变。十/三十站使用已验收V0.3配置生成器的三个通信区域及独立电气馈线，不复制站点代码。控制命令选取实际非目标站，不能继续固定使用可能属于目标区域的PV03。

预声明六类各40次独立任务，共240次，不计入历史已保留实验。每类包含三站4次、十站12次、三十站24次；同类三档强度按原V1.3轮换，单站/站点组/区域范围轮换，背景使用既有N03的三历史日期及模型云影变体。每次独立seed在800000系列唯一，网络种子同步确定；这些是开发验收实验，不声称正式30分钟样本或现场参数。A02两个单向方向都覆盖。A05延后否定确认不支持组合继续在配置阶段拒绝。

先执行scale-10六类区域试验，再执行scale-30六类区域试验；只有前一级机制、数据及独立标签QC通过后启动下一级。其余coverage矩阵228次。三份矩阵合计恰好40次/类，任务名及种子互斥。每项最多一次尝试；失败全部保留、如实报告，不用重试或窗口数凑足覆盖。需要补测时使用新的预登记任务，不覆盖原件。40次是目标，配置文件及单元测试不计为实际运行。

矩阵由scripts/create_v04_fault_matrix.py以排他写入生成，保留原始字节哈希；队列另外冻结规范化配置哈希、代码SHA及逐产物哈希。管理任务ID含机制，仅供Oracle实验管理，实际run_id仍为无类别UUID，不进入M0/M1/M2接口或特征。与配对矩阵和校准种子/日期用途分别记录，不根据检测结果选择运行。
