# ADR 0024：有限、可续跑的验收队列

日期：2026-11-26。状态：8519edb的真实串行队列及完成后续跑验证已通过，报告为2026-11-26-v04-batch-pipeline.md；不代表已满足重复覆盖或吞吐门禁。

批量配置0.4-batch.1组合现有正常、单故障及配对契约。执行仍调用run_isolated或run_pair、既有parse、Arrow、QC、标签和独立标签QC，不另建仿真运行器。首版最大并发固定1；并发吞吐尚未测量，不能声称支持多实例并行数据生产。

每个任务最多1～3次尝试，固定配置的首次有效尝试贡献覆盖数；失败和中断占用重试预算并保留独立attempt目录。新运行和配对使用不含场景类别的UUID，source_group_id继承历史来源。配对数据质量有效但业务对照不成立或流量不匹配，不触发为追求匹配而重试。分别累计尝试/有效/业务对照/匹配配对数，不将站点及窗口数量当作独立运行。

队列manifest原子写入，SQLite独占写锁只保护执行器，不阻塞状态文件读取；进程退出由OS释放锁。续跑要求相同冻结代码及矩阵哈希，并逐一验证已有产物路径、字节数和SHA256。已完成任务不重复执行。运行中的实时协议不能恢复到中途；崩溃后的尝试记interrupted，只有剩余预算允许全新运行。任何故障均不删除或覆盖原证据。

保留策略复用现有RetentionPolicy。开始前根据V0.3实测1,383,250,188 B/h及1.5余量核算整个矩阵（含最大重试）留存预算；每次启动检查剩余配额、最小空闲及11,275,084,964 B历史单PDML临时文件下限。该下限不冒充全流程临时峰值；实际峰值、压缩吞吐及并发仍待独立验证。逐尝试索引完整文件哈希及实际留存字节。默认50GiB验收输出配额，超预算不启动，不授权720小时正式生成。

配对评估矩阵预声明四类型各三次，种子6000～6032、原开发模板三个不同历史日及业务条件，与6组正常校准日期10/11和种子4000系列隔离。规则及阈值先冻结，所有结果保留，不依据测试结果调整。本矩阵不替代六类P0各40次独立覆盖任务。
