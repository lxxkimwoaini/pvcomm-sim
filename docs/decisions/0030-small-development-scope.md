# ADR0030：当前开发收敛到3站，最多10站

2026-11-27。状态：历史临时安排，已由ADR0031及正式科研范围调整取代；下文保留当时记录。

用户要求“先搞3个最多10个站点就ok了”，并要求缩短开发反馈周期。当前默认使用3站，只在多站点或区域机制确需验证时使用10站。暂停30站复验、剩余228项覆盖矩阵及每类40次的批量推进；这些属于后续扩展，不再阻塞当前小规模交付。V1.3原文及历史验收记录保留，不将小规模交付宣称为原完整V0.4通过，也不自动进入V0.5。

新Web请求和授权消费者只执行3/10站，站点范围统一定义在config/workbench.py。保留ExperimentRequest及仿真配置对历史30站记录的读取能力，已有协议、电力、数据和标签契约不变。旧30站排队请求记为deferred_scope并继续处理后续小任务；不修改其原请求、配置、PCAP或仿真报告。独立CLI的大规模历史复现能力保留，本轮不调用。

已通过的三站机制、正常场景、配对和十站证据直接复用。只运行本次接口变更相关单测、契约检查和一个三站API→授权消费者→真实c104→解析/标签/QC回归，不重跑全部异常机制或长时资源测试。新缺陷才追加针对性验证。质量数值、真实协议、观测隔离和因果时间门槛不变。
