# ADR0006：V0.3 场景时间与增量证据读取

2026-11-25，实施中。保留0.1/0.2配置和历史证据语义。

现状：clock_origin在创建资源前捕获，物理模型相对它推进，而主站在连接/总召唤后定义业务起点；初始化耗时改变云影相对于业务的相位。0.3采用独立场景起点屏障；宿主UTC/单调映射保持原义，场景elapsed在屏障前固定为0。起点发布后真实1×，通信暂停不暂停物理模型。起点和历史气象起点共同写运行元数据，供独立QC重算。

IPC追加JSONL适配drvfs，继续保留原始事件，不依赖替换现有路径的原子性。快照尾读采用固定上限并拒绝过长记录；读取最后完整换行，未完整尾保留上次记录，完整坏行失败。Web需要单独增量索引，严格只从observed主站白名单建立投影，按available_at作有界分页和降采样；索引可重建，不修改原始证据。

物理计算有效性、设备故障、通信状态、电网越限分开，越限不能生成通信异常标签。额外物理诊断增加版本化真值证据，不改旧六表，不把Oracle数据送入M2。
