# ADR 0022：预冻结流量相似性与独立正常重复校准

日期：2026-11-26。状态：规则与代码冻结准备，阈值尚未实测生成。本决策不更改原数据质量、解析、抓包、时间或业务验收门槛。

使用configs/v0.4-similarity-policy.json及0.4-similarity.1契约。分析窗口固定为相应实验计划事件前5秒至计划作用结束后20秒，两成员相同；只用P0原始抓包解析出的TCP/IP包，含真实确认、重传和无负载包，不增删或改时标。气象、注入、标签与终端真值不作为流量特征。窗口选择为离线配对协议，不构成模型在线特征授权。

每个目标站分别与全局分别计算上下行包数、字节、包长均值和固定直方图、IAT均值/P50/P95及固定直方图、首末包有效持续时间、每秒速率和速率直方图、峰值包率、突发数与突发包占比。突发定义为相邻间隔≤0.1秒且至少3包；空流量保留零计数及零分布。分布上边界预先固定，溢出单独保存；IAT分位数明确为固定直方图上边界估计，不冒充精确分位数。

标量距离为abs(a-b)/max(abs(a),abs(b),epsilon)，IAT epsilon为1ms，其余1e-9；分布距离为以2为底Jensen–Shannon散度的平方根。两个空分布距离0，单方为空距离1。所有方向、所有特征、每个目标站及全局必须分别满足阈值才进入困难配对子集，不能以全局平均稀释局部差异。

总体方案没有数值匹配阈值。按用户要求使用独立开发校准，而不根据已验收四组或新测试结果拟合。预先固定六组正常重复：N01/N09/N10各两个不同种子与2024-06-10/11背景，每组两次独立真实运行，共12次，window=[15,115)秒。每成员须通过原正常QC、标签及独立QC且所有站valid/false。校准场景、种子、网络种子及历史日期在scenario/calibration.py和运行前plan.json冻结。

local/global分别对每项距离取六组正常重复的最大值，threshold=min(1,max(0.05,1.25*max_distance))。0.05为开发距离分辨余量，1.25为预先声明工程裕量，不是现场限值或置信区间。小样本校准仅支持当前开发子集，不声称统计保证。阈值文件、校准原件、记录及代码哈希必须在新配对测试开始前冻结；不得看测试匹配率后调整。同一校准run禁止再次作为评估候选。既有四组只能作为回顾性评估，未匹配仍为有效对照，不算无效实验。

流量JSONL只扫描一次，固定窗口内容用临时磁盘排序及8MiB SQLite缓存完成局部/全局统计；这是计算临时文件而不是正式报文数据库，退出显式关闭并清理。保留原PCAP、解析和所有QC。进一步标签索引及批量性能验证属于后续切片，不能据此宣称正式720小时吞吐已验证。

匹配报告单列evaluation_valid、业务对照、matched、hard_pair_selected；运行失败、数据无效、对照不成立与流量未相似必须分别计数。批量报告以独立run/pair计尝试、有效、对照与匹配数，不以站点或窗口替代。未开始V0.5，未用检测模型或未来测试集挑选样本。
