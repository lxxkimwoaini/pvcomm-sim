# V0.1 最小 IEC 104 协议原型实施计划

日期：2026-11-25。依据：`AGENTS.md`、V1.3 方案第 5、6、11、17、21 节。

## 范围

本切片实现本机 WSL2 授权实验环境中的 1 个 c104 主站和 3 个独立 c104 RTU 服务端。独立端点模式使用 4 个 namespace、3 对内部 veth 和独立进程；回环模式仅用于开发验证。每个 RTU 使用独立 TCP 端口和公共地址，提供有功、无功、电压遥测、已接受有功设定值、运行状态和有功设定值命令。主站建立真实 TCP/IEC 104 连接，执行启动、总召唤、有功限发和解除限发；RTU 在合法命令到达并接受后更新设定值，设备状态随后按斜率更新实际有功。

同时记录 tcpdump 原始 PCAP、c104 双端原始 APDU 回调、主站业务事件、终端事件和设备状态。输出按 `run_id` 隔离，运行配置和清单写入输出目录。网络仅在本次拥有的 namespace 内创建，不修改宿主路由；当前切片不生成正式数据集。Q/U 是明确标注的协议测试常量，P 是固定可用功率及斜率测试模型。

## 文件与职责

- `src/pvcomm/config/lab.py`：V0.1 严格配置模型及 YAML 加载。
- `src/pvcomm/capture/tcpdump.py`：tcpdump 启停、接口和退出状态记录。
- `src/pvcomm/protocol/c104_runtime.py`：c104 RTU、主站、点表和回调适配。
- `src/pvcomm/scenario/v01_runner.py`：唯一运行编排、时间线、输出和清理。
- `src/pvcomm/scenario/isolated_runner.py`、`lab_worker.py`、`network/isolated.py`：独立端点编排、固定角色子进程及资源清理。
- `src/pvcomm/storage/events.py`：并发日志、端点唯一 ID、观测/真值隔离。
- `src/pvcomm/pipeline/iec104_parser.py`：版本化 PDML 包/APDU/对象解析。
- `configs/v0.1-lab-smoke.yaml`：短时冒烟配置。
- `configs/v0.1-lab-30m.yaml`：V0.1 正常运行配置，目标 30 分钟。
- `tests/lab/test_v01_runtime.py`：显式标记的真实协议集成测试。

## 测试与验收

1. 普通 Python 检查、schema、前端检查及新增回归测试通过。
2. WSL 中运行短时真实 c104 测试，检查 3 个连接均为 `OPEN`，3 次总召唤、限发和解除限发均有主站事件及 RTU 接受事件。
3. PCAP 能由 tcpdump 生成且包含 2404 业务以外的配置端口流量；TShark 能识别 `iec60870_104`/`iec60870_asdu`。
4. 输出清单记录配置哈希、代码 SHA、工具版本、捕获退出状态和实际运行状态；异常退出也保留目录。
5. 30 分钟正式 V0.1 门禁仍需单独运行并核对包计数、解析率、日志关联 P99 和资源清理，未完成前不标记 V0.1 通过。

## 冒烟实施结果（2026-11-25）

短时真实运行与显式 `pytest -m lab` 已通过。随后复核并修正独立端点、解析、真值隔离和资源清理问题。独立 namespace/veth 及取消回归已通过；两个旧回环 30 分钟记录只保留为稳定性证据，不满足整阶段门禁。详见 progress 最新记录。

## 证据完整性修正切片（2026-11-25）

审查发现：同一回环接口的两个 tcpdump 不是 P0/P1 独立端点；原字段平铺解析把包与 APDU 一对一，丢失合并 APDU 及纳秒精度；观测文件包含终端真值；记录器未同步；斜率更新可能把命令到达前时间计入新目标。此前冒烟仅证明会话和命令可达，不证明 V0.1 完整验收。保留所有既有运行，不覆盖或删除。

本切片先修复上述问题及抓包 readiness/丢包统计、取消清理、配置边界、代码快照，再实现仅包含本次资源的 namespace/veth 前置验证和独立端点冒烟。新增普通回归测试覆盖并发记录、真值隔离、斜率、重复配置键、多 APDU、多对象、时间精度和失败保留。完整 P0/P1、30 分钟、对照、QC 和只读 Web 尚未全部满足前继续保持 V0.1 未验收。后续在功能分支提交并发起 PR，不自动合并。

## 风险与边界

- c104 2.2.1 的回调签名由扩展模块严格检查，适配层必须保留实测签名。
- 回环抓包证明协议报文和本机实验链路，不代表物理网络或现场性能。
- 当前设备状态使用明确的容量、可用功率和斜率仿真假设；气象、潮流和异常注入留待 V0.2/V0.4。
- 输出 JSONL 是 V0.1 运行证据的临时交换格式，正式 Parquet 解析和数据集契约仍待后续阶段。
