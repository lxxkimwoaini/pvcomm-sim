# V0.1 验收补齐计划

日期：2026-11-25。依据 AGENTS.md、V1.3 第 5/6/9/10/11/12/15/17/21 节。基于已验证修复分支继续开发，不自动合并 PR。

1. 固定独立端点配置（每站独立地址、2404），记录实际协议计时器；保留既有回环配置兼容。增加只用于授权隔离实验的单站停止/恢复与事先可用维护计划，所有注入信息进入 truth。
2. 冻结并提交运行代码，用只读代码快照执行 1800 s 正常运行；不在运行中修改快照。旧回环证据不替代本次验收。输出根唯一，不删除失败运行。
3. 建立独立 PCAP/TCP 流重组核验，与 TShark 和 c104 原始回调逐字节对应，报告完整 APDU 分母、截断/未匹配、P99 映射误差。核验 3 站总召唤和命令→接受→实际功率反馈，不能按最近时间估配。
4. 版本化 Parquet 导出采用显式 Arrow 类型和单位，JSONL 继续保留；配置/代码/原始输入哈希及派生清单可追溯，原子写入且拒绝覆盖。新增依赖仅用于解析/验收，不成为协议运行前提。
5. 完成维护/非计划中断对照，保持共享站点、种子、时间计划和网络；从 P0 实测中断及恢复、维护计划 available_at 核验业务口径。验收标签为开发审计产物，不冒充 V0.4 冻结数据集。
6. 只读 Web 从服务端显式配置的输出根读取主站可观测白名单；按游标 available_at 过滤，禁止任意路径、truth/P1/注入或未来信息。实现运行选择、3 站拓扑、功率曲线、事件/协议列表，断网、空数据、移动端均可验证。
7. 单元/契约、普通 CI、真实协议/清理测试及真实后端浏览器验收；在冻结代码上完成 30 min 和两个对照运行，生成逐门禁报告、记录失败/局限，提交并推送 PR，禁止自动合并。

验收：完整 APDU 解析率≥99.5%，工具报告丢包为 0，日志映射 P99≤100 ms；3 站遥测/总召唤/有功调控和 P0/P1 对账通过；真实 1800 s、对照及恢复证据齐全；M2 Web 与原始可观测记录一致。任何未测量或失败项保留失败，不降低阈值，不进入 V0.2 正式验收。
