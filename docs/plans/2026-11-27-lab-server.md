# 实验室服务器部署切片

本切片依据用户明确授权，将现有三站实验迁至实验室 Linux 服务器。继承V1.0生产计划、测试来源和原质量门禁，不更改仿真核心、标签、特征、站点数或前端。

执行范围：核验系统和存储；按原uv.lock安装Python 3.11及protocol/data/power依赖；复制并核验历史气象输入；在用户目录补齐抓包与NetEm工具；运行一次既有三站正常业务部署冒烟，完成真实P0/P1、解析、Arrow、正常业务及独立标签QC和资源清理。源码与输出分开冻结，失败记录保留。

服务器根分区容量较小，数据、工具、日志及缓存使用/home下的用户目录。用户命名空间已由系统允许时使用现有UID及命名空间内能力；私有网络没有宿主默认路由，/run挂载传播隔离。不使用sudo、不改变宿主安全设置，不向服务器复制SSH私钥。若该路径不可用，明确报告阻塞，不删除NetEm seed或降低抓包门禁。

本地已有正式测试及后续24小时任务仍由原冻结驱动消费。部署期间保留本地运行，不在服务器重复消费相同任务。服务器验证后冻结独立任务清单，明确宿主归属及未启动状态；接续生产前先核对两端清单和活跃进程。部署冒烟本身不计作新的正式独立测试。

验收依据实际日志、原气象SHA、版本清单、完整APDU对账、工具drop、日志对齐、业务及标签QC、namespace清理及磁盘占用。不以安装成功代替真实实验通过；不以已排队时长代替已完成时长。交付部署命令、报告、进度及普通Git推送，原始证据仅留授权本地/服务器存储。
